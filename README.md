# ЄФВВ Quiz — педагогіка та вчені

Красивий статичний вебтест для підготовки до ЄФВВ на основі конспекту з педагогіки та психології.

## Що всередині

- **118 питань** українською мовою.
- Акцент на темах **педагогіка**, **дидактика**, **виховання** та **вчені**.
- Категорії для окремого тренування.
- Перемішування питань і відповідей.
- Пояснення після кожної відповіді.
- Режим повторення помилок.
- Збереження найкращого результату в браузері.
- Світла/темна тема.
- Без бекенду, бази даних і встановлення залежностей.

## Як запустити локально

Варіант 1 — просто відкрий `index.html` у браузері.

Варіант 2 — через локальний сервер:

```bash
python -m http.server 8000
```

Після цього відкрий у браузері:

```text
http://localhost:8000
```

## Як залити на GitHub Pages

1. Створи новий репозиторій на GitHub.
2. Завантаж усі файли з цієї папки в репозиторій.
3. Відкрий **Settings → Pages**.
4. У полі **Branch** вибери `main` і папку `/root`.
5. Натисни **Save**.
6. Через кілька хвилин GitHub дасть посилання на сайт.

## Як додати питання

Відкрий файл:

```text
assets/js/questions.js
```

Додай новий об’єкт у масив `QUESTION_BANK`:

```js
{
  id: 999,
  category: "Вчені",
  difficulty: "medium",
  question: "Хто є автором теорії вчинку?",
  options: ["Віктор Роменець", "Ян Амос Коменський", "Карл Роджерс", "Б. Скіннер"],
  answer: 0,
  explanation: "Віктор Роменець відомий як автор теорії вчинку."
}
```

> `answer: 0` означає, що правильна відповідь — перший варіант у масиві `options`.
