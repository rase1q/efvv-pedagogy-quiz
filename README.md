# ЄФВВ Quiz — повний банк питань

Інтерактивний GitHub Pages тест за файлом `ЄФВВ.docx`.

## Що всередині

- 298 питань для підготовки до ЄФВВ
- 7 категорій: Виховання, Вчені, Дидактика, Методи дослідження, Педагогіка, Професійна діяльність, Психологія
- питання по всьому файлу: педагогіка, психологія, вчені, методи дослідження, дидактика, виховання, професійна діяльність
- пояснення після кожної відповіді
- режим повторення помилок
- перемішування питань
- збереження найкращого результату
- світла/темна тема

## Як оновити GitHub

Якщо репозиторій уже створений, просто заміни файли:

- `index.html`
- `styles.css`
- `questions.js`
- `app.js`
- `favicon.svg`
- `README.md`
- `QUESTION_BANK.md`

Після завантаження натисни `Commit changes` і онови сайт через `Ctrl + F5`.

## GitHub Pages

Settings → Pages → Source: `Deploy from a branch` → Branch: `main` → Folder: `/ root` → Save.
